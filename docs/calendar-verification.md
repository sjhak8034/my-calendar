# 캘린더 날짜·레인 로직 검증 목록

`lib/calendar/`의 순수 함수를 검증하는 입력 → 기대값 표다. 기대값은 `Date.UTC`로 직접 계산하거나 손으로 계산한 값이며, 구현 코드를 거치지 않는다. 실행 환경의 `TZ`(UTC, Asia/Seoul, America/Los_Angeles)와 무관하게 같은 결과여야 한다.

규칙: 주 시작 월요일(`WEEK_START`), 월 그리드 6주 × 7일 = 42칸, 타임존 Asia/Seoul. 아래 날짜는 모두 `YYYY-MM-DD`.

## 1. 월 그리드 `getMonthGrid(year, month)`

| 입력 | 1일 요일 | 첫 칸 | 마지막 칸 | inMonth 수 | 비고 |
| --- | --- | --- | --- | --- | --- |
| 2026-10 | 목 | 2026-09-28 | 2026-11-08 | 31 | 첫 주는 월~수가 9월 |
| 2026-08 | 토 | 2026-07-27 | 2026-09-06 | 31 | 첫 주 inMonth = 토·일만 true |
| 2026-03 | 일 | 2026-02-23 | 2026-04-05 | 31 | 1일이 첫 줄 마지막 칸 |
| 2026-11 | 일 | 2026-10-26 | 2026-12-06 | 30 | |
| 2027-02 | 월 | 2027-02-01 | 2027-03-14 | 28 | 5·6번째 주는 전부 3월(inMonth false) |
| 2027-01 | 금 | 2026-12-28 | 2027-02-07 | 31 | 연도 경계: 12월 날짜로 시작 |
| 2028-02 | 화 | 2028-01-31 | 2028-03-12 | 29 | 윤년 |

공통: 행 6개, 각 행 7칸, 42칸이 하루씩 연속, 첫 칸은 항상 월요일.

## 2. 윤년과 날짜 유효성

| 입력 | 기대값 |
| --- | --- |
| `isValidDate("2028-02-29")` / `("2000-02-29")` | true / true |
| `isValidDate("2027-02-29")` / `("2100-02-29")` | false / false |
| `weekdayIndex("2028-02-29")` | 1 (화) |
| 2028-02 그리드에서 2028-02-29 위치 | 5번째 주(인덱스 4), 열 1 |
| 2027-02 그리드에 2027-02-29 | 없음 |
| `endOfMonth("2028-02-10")` / `("2027-02-10")` | 2028-02-29 / 2027-02-28 |
| `addDays("2028-02-28", 1)` | 2028-02-29 |
| `diffDays("2028-01-01", "2029-01-01")` / 2027→2028 | 366 / 365 |

## 6. 서울 날짜 변환과 `eventDateSpan`

| 입력 | 기대값 |
| --- | --- |
| `toSeoulDate("2026-10-24T15:00:00Z")` | 2026-10-25 |
| `toSeoulDate("2026-10-24T14:59:59Z")` | 2026-10-24 |
| `toSeoulDate("2026-12-31T15:00:00Z")` | 2027-01-01 |
| `todayInSeoul` (2026-10-25T14:59:59Z / 15:00:00Z) | 2026-10-25 / 2026-10-26 |
| 같은 날 오후 (10/25 14:00~15:00 +09:00) | 10/25 ~ 10/25 |
| 자정 넘김 (10/25 22:00 ~ 10/26 02:00) | 10/25 ~ 10/26 |
| 정확히 00:00 종료 (10/25 22:00 ~ 10/26 00:00) | 10/25 ~ 10/25 |
| 종일 3일 (10/25 00:00 ~ 10/28 00:00) | 10/25 ~ 10/27 |
| UTC 10/24 05:00 ~ 15:00 (= 서울 10/24 14:00 ~ 10/25 00:00) | 10/24 ~ 10/24 |
| 시작 = 종료 (같은 시각) / 00:00에서 시작 = 종료 | 그 하루 |
| 종료 00:00:01 (10/26) | 10/25 ~ 10/26 (정각이 아니므로 포함) |
| 종료가 시작보다 빠름 | 시작 하루로 보정 |

## 7. 주 조각 `splitIntoWeekSegments` (2026-10 그리드: 0주 = 9/28~10/4, 1주 = 10/5~, 3주 = 10/19~10/25, 5주 = 11/2~11/8)

| 10/7 ~ 10/21 (3주) | [1,2,6,F,T], [2,0,6,T,T], [3,0,2,T,F] |
| 10/25 ~ 10/25 (하루) | [3,6,6,F,F] |

| 11/6 ~ 11/20 (그리드 뒤로 벗어남) | [5,4,6,F,T] |

## 8. 레인 `layoutWeek` (maxLanes 기본 3)

| 입력 | 기대값 |
| --- | --- |
| 종일 막대 열0~3 + 열1 단일 2개(09:00, 10:00) | 막대 lane 0, 09:00 lane 1, 10:00 lane 2, hidden 없음 |
| 종일 x(0~1), z(1~2), y(2~3) | x 0, z 1, y 0 (겹치지 않는 첫 레인 재사용) |
| 같은 날(열2) 단일 5개 | lane 0,1,2 visible, 3,4 hidden, `hiddenByDay[2] = 2` |
| 같은 날 단일 4개 | `hiddenByDay[0] = 1` |
| 단일 3개(열1) + 다일 막대(열1~3) | 막대 lane 0, 단일 lane 1,2,3, 마지막이 숨겨져 `hiddenByDay[1] = 1` |
| 정렬: 단일 08:00, 종일 단일, 열0~4 다일, 열0~1 다일 | 열0~4 다일 → 열0~1 다일 → 종일 단일 → 단일 08:00 |
| `maxLanes: 1`, 같은 날 2개 | `hiddenByDay[0] = 1` |
| 입력 배열 | 변이되지 않음 |

## 실행 방법

테스트 러너는 없다. 일회성 스크립트(저장소에 두지 않음)로 `lib/calendar/*.ts`를 `typescript`의 `transpileModule`로 CJS 변환한 뒤, 위 표를 `TZ=UTC`, `TZ=Asia/Seoul`, `TZ=America/Los_Angeles`에서 각각 실행한다.
